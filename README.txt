VIDEOHELP - COMO RODAR

1. Abra o CMD dentro da pasta VideoHelp.
2. Ative o ambiente virtual:
   venv\Scripts\activate

3. Instale as dependências:
   pip install -r requirements.txt

4. Rode o site:
   python app.py

5. Abra no navegador:
   http://127.0.0.1:5000

IMPORTANTE:
- O projeto foi feito para vídeos públicos e para conteúdo que você tenha permissão para baixar.
- Não tente baixar conteúdo privado, protegido por login ou por DRM.
- O download é feito pelo navegador; em um celular, o arquivo será salvo/aberto de acordo com o navegador.
- Plataformas podem mudar seus sistemas e fazer alguns links deixarem de funcionar.
